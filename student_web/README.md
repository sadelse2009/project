# Веб-приложение «Личный кабинет студента»

Командный проект (6 спринтов) по веб-разработке на Python (Flask) + HTML/CSS + JSON.

## Установка и запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите сервер: `python3 app.py`
3. Откройте сайт в браузере: `http://127.0.0.1:5000`
4. Запуск автотестов: `python3 -m pytest`
